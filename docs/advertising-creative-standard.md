# 숏폼 광고의 실사·카피·영상미 기준

이 스튜디오의 광고 제작 기본값이다. 2026-10-02 사용자는 가능한 실사풍, 영상미와 속도감, 탁월한 카피를 요구하고 모션그래픽은 목적 또는 사용자 요청에 따라 선택하도록 지시했다. 브랜드와 매체에 맞게 적용하며 사용자의 명시한 스타일·속도·음향을 우선한다.

## 1. 표현 방식을 먼저 결정

- 기본은 `photoreal_ad`: 사람의 표정·행동·물건·환경이 이야기를 전달하는 시네마틱 실사풍 광고다. AI 생성 실사풍과 실제 촬영/제공 소스를 구별해 출처를 기록한다. 실제 수강생·후기·성과·행사 기록으로 AI 장면을 오인시키지 않는다.
- `hybrid_ad`: 실사풍 사건 위에 필요한 UI·일정·키네틱 타이포·제품 설명을 결합한다. 장면을 이해시키는 그래픽만 넣는다.
- `motion_graphics`: 사용자가 요구하거나 추상 개념·제품 작동·브랜드 표현에 그래픽이 더 적합할 때 선택한다. 선택 이유를 기록하고 [모션 디자인 기준](motion-design-standard.md)을 적용한다. 기본이 실사라는 이유로 명시적 모션그래픽 요청을 거절하지 않는다.
- 브랜드의 색·폰트는 실사 위의 자막·UI·엔드카드에도 적용할 수 있다. 브랜드 맵이 그래픽 화면을 요구하지 않는 한 색상표를 전체 영상의 도형·카드 구성으로 확대해석하지 않는다.
- 사용 가능한 고품질 이미지/영상 생성 도구를 실제 연결·현재 결과·승인·사용권으로 판단한다. Codex에서는 연결된 imagegen 등을, Claude에서는 승인된 PixVerse 등 해당 환경의 도구를 검토한다. 도구 이름이나 모델 이름만으로 우월함을 주장하지 않는다. 좋은 스틸은 좋은 모션을 보장하지 않는다.
- 실사풍 도구가 없거나 호출/권리 확인이 막히면 해당 생성 단계만 BLOCKED로 남긴다. 대본·컷 설계·가능한 소스 검토는 계속하고, 편하다는 이유로 전편을 도형 그래픽으로 조용히 대체하지 않는다. 스틸 기반 구성이 필요하면 스토리보드/애니매틱 여부와 운동의 한계를 명시한다.
- Producer가 추천안과 표현 방식을 판단하고 기존 자동 진행·승인 재사용 규칙을 적용한다. 스타일이나 단계마다 다시 묻지 않는다. 새 결제·계정 확장·외부 공개 권한은 확대하지 않는다.

## 2. 광고 카피: 한 사람에게 한 행동을

Story는 [내레이션 글쓰기 기준](../.agents/skills/studio-story/references/narration-writing.md)의 im-not-ai 요약·각색 규칙을 유지하면서 광고의 설득을 점검한다.

- 타깃의 구체적인 망설임 하나, 제공 가치 하나, 근거가 있는 믿을 이유, 실행 가능한 행동 하나를 고른다. 서비스 설명만 나열하지 않는다.
- 첫 3초의 훅은 타깃이 겪을 질문·행동·상황과 연결한다. 추상적인 선언, 근거 없는 충격 숫자, 반복하는 “해본 적 있으시죠?” 공식을 쓰지 않는다. 교육 광고에서 두려움이나 부모의 죄책감을 부풀려 관심을 끌지 않는다.
- 훅 3개·전체 초안 2개를 만들어 시청자 관련성, 말의 자연스러움, 구체성, 차별성, 다음 장면 기대, 행동의 명료함을 비교한다. Producer가 추천안과 이유를 남기고 자동 제작에서는 바로 이어간다.
- `full_narration`은 소리만 들어도 이어지는 말로 작성하고 장면을 붙인다. 광고 문장과 장면을 함께 다듬어 말과 화면이 각각 새 역할을 맡게 한다. 핵심 카피·자막·날짜·기관명을 동시에 경쟁시키지 않는다.
- 30초 약 210자(공백·구두점 포함)는 시작 추정치이며 실제 발화·호흡·장면 읽기 시간으로 조정한다. 대본을 덜어 내지 않고 배속으로만 밀어 넣지 않는다. 명확한 모집/교육 기간은 서로 구별하고 글자 수 때문에 오해를 만들지 않는다.
- 사용자 제공 정보와 검증 사실을 구별한다. 없는 성과·무료 혜택·신청 링크·기관 역할을 카피를 강하게 만들 목적으로 발명하지 않는다. CTA는 현재 확인된 신청/행동 경로와 일치시킨다.
- SCRIPT의 `ad_copy_review`에 `audience_tension`, `single_benefit`, `reason_to_believe`(근거/한계), `hook_scene_pair`, `distinctive_line`, `cta`, `rejected_cliches`, `producer_choice_reason`을 남긴다. 기존 SCRIPT 출력과 체크리스트에 추가하며 자체 점검을 독립 QA로 바꾸지 않는다.

## 3. 영상미: 인물·빛·구도·행동의 연속성

- Director가 타깃/브랜드에 맞는 인물과 공간, 화면에서 실제로 일어나는 동작, 카메라 거리·각도·시선, 조명 방향과 대비, 컬러·피부톤·재질·심도 의도를 정한다. “cinematic” 한 단어를 붙이는 것을 연출로 취급하지 않는다.
- Art는 얼굴·연령대·헤어·의상·주요 소품·공간의 일관성을 인물/공간 시트와 기준 이미지로 관리한다. 장면마다 다른 사람처럼 바뀜, 손·접촉·시선·기기 원근·문자 오류를 실제 출력에서 확인한다. 같은 첫 이미지 하나를 매 장면 확대하는 것으로 통일성을 대신하지 않는다.
- 전체 상황 → 시선/표정 → 손과 물건의 행동 → 결과/반응처럼 장면의 원인과 결과에 맞는 거리·시점을 설계한다. 다양성 자체를 위한 컷과 무관한 고급스러운 스톡 이미지를 끼워 넣지 않는다.
- 실사풍 컷의 움직임은 실제 사건/반응에서 만든다. 카메라 이동은 주시 대상이나 정보 공개를 돕고, 인물이 매번 정면에서 노트북을 들고 있는 구도는 관성적으로 반복하지 않는다.
- 생성 장면에 정확한 한글/날짜/로고를 직접 그리게 하지 않고 필요할 때 편집 레이어로 합성한다. 얼굴·손·시연 행동을 자막이 덮지 않게 하며, 브랜드 타이포가 인물의 감정을 눌러버리지 않게 한다.
- 생성 결과가 계획과 다르면 프롬프트·참조 이미지·컷·에셋을 수정한다. PNG가 생겼다는 이유로 좋은 에셋이라고 보고하지 않는다.

## 4. 속도감: 의미·강약·사운드의 편집

[몰입·리듬 기준](../.agents/skills/studio-produce/references/attention-and-pacing.md)을 함께 적용한다.

- 첫 프레임부터 사건을 시작하고 첫 3초에 질문/행동/발견이 보이게 한다. 로고 인트로로 시간을 쓰지 않는다. 다음 정보를 기다릴 이유를 훅과 회수에 연결한다.
- 행동의 진입/끝, 반응, 물건의 이동, 시선 방향, 소리의 선행/후행으로 컷을 연결한다. 짧은 디테일 컷과 의미 있는 머무름을 대비시키고, 정보량에 맞춘 읽기 시간을 확보한다. 고정 컷 수·매초 전환·전체 배속을 속도감의 대리 지표로 쓰지 않는다.
- 광고 기본에는 콘셉트에 맞는 BGM과 필요한 사건 효과음을 실제 스템으로 준비한다. 무음/정적 요청은 우선한다. 음성의 명료도와 음악의 감정 곡선을 맞추고, 의미 없는 루프/Whoosh/클릭 반복으로 생동감을 주장하지 않는다.
- 실제 목소리의 발음·억양·강세·호흡, BGM 음색·전개·밀도·피로도, 컷과의 싱크를 청취한다. 무료·로컬·직접 작곡이라는 이유만으로 품질을 인정하지 않는다. 과도하게 빠른 음성을 크레딧 절약의 기본 해법으로 삼지 않는다.
- 3초/8초 시제품은 이 광고의 인물·주요 행동·실제 움직임·카피·음향을 대표해야 한다. 실사풍 본편 계획을 단순 도형 시제품만으로 승인받았다고 취급하지 않는다. 사용자의 단계 확인 생략과 실제 품질 관찰은 구별한다.

## 5. 인계와 검수

`design-packet.json`에 다음 항목을 남기고 역할에 필요한 필드를 넘긴다. 외부 파일을 참조할 때 실제 소스는 기존 ASSET/MOTION/AUDIO 번들 규칙대로 보존한다.

| 항목 | 책임 | 내용 |
| --- | --- | --- |
| `creative_direction` | Producer | mode, selection_source(USER_REQUEST/CONTENT_NEED/DEFAULT), reason, policy_version, 현재 도구·승인·권리 |
| `ad_copy_review` | Story | 타깃의 망설임·가치·근거·훅/장면·차별 카피·CTA·추천 이유 |
| `cinematography` | Director | 인물/공간 시트, 행동, 구도/시점, 빛·색·심도, 주시/전환 이유 |
| `asset_review` | Art | 현재 출력의 동일 인물·손·재질·원근·합성 공간·오류/수정 근거 |
| `rhythm_and_sound` | Motion/Audio/Editor | 비트 타임라인, 속도 강약, 읽기/숨, BGM/SFX 전개와 실제 스템 |
| `motion_design` | Motion(해당 시) | 모션 전문 기준의 타이포·키프레임·이징·안무·변형/공간·소리·작업 소스 |
| `advertising_review` | 독립 Viewer QA | 타임코드별 카피·영상미·속도·음향, 관찰 범위, 문제/복구 가설, 비교작 근거 |

독립 검수는 현재 SHA의 실제 속도 연속 시청·청취로 카피가 타깃에게 남는지, 실사풍 장면의 인물/행동/감정이 자연스러운지, 컷·읽기·사운드의 리듬이 유지되는지 확인한다. 실제 관찰한 상투적/불분명한 카피, 부자연스러운 생성 장면, 반복 슬라이드·정지 구도, 의미 없는 운동, 거친 합성/음향은 해당 게이트 FAIL과 타임코드/레이어/새 복구 가설로 보고한다. 관찰 불가이면 해당 항목은 BLOCKED다. 접촉시트·해상도·LUFS·자가 점수로 광고 품질 PASS를 만들지 않는다.

사용자는 모션그래픽에 Opus 5.5보다 높은 완성도를 목표로 제시했다. 비교가 필요하면 같은 브리프·길이·목적의 실제 비교작을 사용해 카피, 타이포, 구도, 움직임의 설계/마감, 편집/소리, 브랜드 기억과 CTA를 타임코드로 비교한다. 다른 브랜드/주제 결과는 표현 방식 참고로만 구별한다. 비교작/실제 관찰 없이 특정 모델보다 우수하다고 선언하지 않는다. 기준 문서만으로 품질이 달성됐다고 주장하지 않는다.

## 6. 두 도구와 기존 제작

Codex·Claude는 같은 공통 스킬·역할 책임·품질 기준을 사용하고 도구별 어댑터만 달리한다. 자동 진행/권리/독립 QA/불변 원장/날짜·시간별 short 저장 규칙을 유지한다. 이 문서는 창작 선택과 관찰 기준이며 자동 시청률 측정기나 광고 품질 판정기가 아니다. 기존 영상·brief·승인 기록을 덮어쓰지 않는다. 새 정책/역할/실행 코드의 변경으로 기존 원장이 STALE이면 기존 버전을 보존하고 수정 제작은 새 ID/현재 버전으로 등록한다.

## 모션 시퀀스 보완

모션을 선택한 시퀀스는 [공통 모션 기준](motion-design-standard.md)의 장르 선택·스토리보드·사전 애니매틱·모션 토큰을 적용한다. [정량·납품 기준](motion-delivery-spec.md)의 권장값/공식 규격/미확인을 구분하고 [자동 증거→독립 실제 시청](motion-review-protocol.md)으로 검수한다. 자동 증거 확보 후 미관찰은 초안/사람 검수 대기이며 전체 제작을 중단하거나 PASS로 바꾸지 않는다.
