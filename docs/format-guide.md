# 화면 비율별 제작 기준

brief.format으로 비율을 정한다. 지정이 없으면 `config/local.json`의 format, 그것도 없으면 9:16이다. 출력 크기·Pixverse 생성 비율·자막/태그/엔드카드 배치는 렌더러가 비율에 맞춰 자동으로 계산한다. 이 문서는 Story·Director가 **설계할 때** 따르는 기준이다. 수치는 스튜디오 권장 출발점이며 플랫폼 공식 규격이 아니다.

| 항목 | 세로 9:16 | 가로 16:9 | 정사각 1:1 |
|---|---|---|---|
| 출력 | 1080×1920 | 1920×1080 | 1080×1080 |
| 기본 길이 | 30초 | **60초** | 30초 |
| 용도 | 쇼츠·릴스·틱톡 | 유튜브 일반·웹·발표 | 피드 |
| 내레이션 분량(공백 포함) | 약 210자 | 약 420자 | 약 210자 |
| 1편 기본 한도(이미지/클립/TTS자) | 12 / 4 / 800 | 20 / 6 / 1500 | 12 / 4 / 800 |
| 하단 자막 기준선 | 화면 높이 약 76% | 약 84% | 약 76% |
| 자막 한 줄 최대 폭 | 화면 폭 80% | 66% | 80% |
| 플랫폼 UI 피할 영역 | 아래 320px·오른쪽 140px | 하단 진행바 근처 | 상하 여백 |

## 세로 9:16

- 주인공·사건을 화면 가운데 세로축에 둔다. 위·아래는 자막과 플랫폼 UI 자리다.
- 첫 1~3초에 장면 자체의 사건으로 훅을 만든다. 컷은 행동 1~2.5초가 출발점이다.

## 가로 16:9 (60초)

- **구도**: 3분할을 쓴다. 인물·사건은 좌우 한쪽 1/3에 두고, 반대쪽은 정보·화면 UI·키네틱 타이포 공간으로 비운다. 노트북·폰 화면 UI가 있으면 화면이 그 정보 쪽에 오게 생성 프롬프트에 위치를 쓴다(예: "laptop on the right third").
- **이미지 프롬프트**: 세로용 "upper-middle of the frame" 같은 위치 표현 대신 "left/right third", "wide establishing", "over-the-shoulder with screen on the right"처럼 가로 구도로 쓴다.
- **60초 구조**: 훅(0~5초) → 문제·공감(5~15) → 오해 깨기·전환(15~25) → 방법·장면 시연 2~3단계(25~48) → 현실적 기대치(48~53) → 첫 행동·브랜드(53~60). 30초의 비트를 늘이지 말고 **새 정보 단계**를 더한다.
- **리듬**: 30초보다 컷이 조금 길어도 된다(행동 1.5~3초). 같은 구도가 4초를 넘으면 카메라 드리프트나 모션 사건으로 변화를 준다. 장(章)이 바뀌는 곳에 시각적 전환을 하나 둔다.
- **자막**: 한 줄 위주, 화면 아래 중앙. 키네틱 타이포는 비어 있는 쪽 1/3에 둔다.
- **이미지·클립 수**: 60초는 보통 이미지 12~16장, 클립 3~5개로 설계하고 나머지는 모션·카메라 운동으로 채운다(한도 20/6 안).

## 정사각 1:1

- 가운데 정렬 구도. 자막은 아래 1/4 안. 30초 기본, 세로와 같은 리듬.

## 공통

- 비율을 바꾸면 기존 이미지·클립을 재사용하지 않고 그 비율로 다시 생성한다(크롭 재사용은 구도가 깨진다).
- 모션 장면 props의 좌표는 해당 비율의 픽셀 기준이다(`"box": "screen"`, `"origin": "screen"`은 자동 측정).
