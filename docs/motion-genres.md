# 모션 장르별 부록

[공통 기준](motion-design-standard.md) 아래에서 필요한 장르만 선택한다. 혼합 작품은 시퀀스별 장르와 연결 이유를 기록한다. 아래 지속시간은 스튜디오 시작 권장값이며 사용자 분량과 실제 읽기·기능 목적이 우선한다.

| 장르 | 좋은 결과와 설계 | 반드시 남길 검수 근거 |
|---|---|---|
| 로고 스팅거 | 보통 2~4초 안에 예고→형태/의미 전환→식별 가능한 정착으로 완결. 기존 로고 비율·자간·색을 지키고 마지막 식별 시간 확보. 별도 CTA를 억지로 붙이지 않는다. | 로고 규정, 정착 시간, 마지막 프레임, 정상 속도 식별·소리의 마감 |
| 데이터 시각화 | 수치·단위·출처·기간을 정확히 표시. 막대 길이/면적/축이 수치와 일치하고 축 절단·로그·정규화는 드러낸다. 변화량을 과장하는 이징/오버슈트를 피한다. | 원자료 해시, 값→픽셀 매핑, 축·범례, 중간/최종값 정확성, 출처 가독성 |
| 키네틱 타이포 | 발화·강세와 핵심 단어 등장/정착을 연결. 구·의미 단위로 읽히게 하고 한글 음절을 무작위로 흩뜨리지 않는다. 무음판에서도 문맥과 위계가 유지된다. | 단어/구 발화 타임코드와 안정 노출 구간, 실제 싱크 오차, 읽기·무음 검수 |
| UI 모션 | 행동→피드백→상태 변화의 기능이 먼저다. 예시 권장 0.10~0.25초 피드백, 0.20~0.40초 화면 연결. 로딩 시간은 실제 시스템 상태와 일치. 사용자가 구현물을 요청하면 reduced-motion 대안 제공. | 실제 기능 상태/트리거, 응답 타이밍, 포커스·터치 영역, reduced-motion 동작. 데모 영상과 작동 UI를 구별 |
| 소셜 루프 | 마지막→첫 프레임 위치·속도·밝기·배경과 오디오가 자연스럽게 이어짐. 첫 사건이 반복 시에도 이해된다. 광고 루프라면 CTA가 반복 흐름을 깨지 않도록 설계. | 경계 전후 프레임, 속도/오디오 경계, 최소 3회 반복 정상 속도 확인. 끝 프레임을 복제해 잠깐 멈추는 것으로 무봉합을 주장하지 않는다. |
| 설명/브랜드 필름·광고 | 질문→사건→발견→회수의 새 정보와 브랜드 기억을 함께 설계. 실사/모션 혼합의 전환에 정보/시점 이유 부여. | 타이깃·핵심 메시지, 애니매틱 리듬, 무음 이해, 실제 신청/행동 경로, 장면별 읽기 시간 |

장르마다 정착의 의미가 다르다. 데이터를 비교하거나 로고를 식별하는 의도적 정지는 결함이 아니다. 반대로 단어만 교체하는 정지 카드를 키네틱 타이포로 이름 붙이지 않는다.
