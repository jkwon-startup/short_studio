# 향후 Codex·Claude 선택 배포

사용자의 향후 GitHub 배포 방향을 기록한 설계 문서다. 현재 push·commit·remote 변경은 하지 않았다.

현재 프로젝트는 홈 디렉터리의 Git 저장소 아래 있다. 배포는 프로젝트 소스만 선별한 독립 디렉터리와 독립 저장소에서 준비한다. 홈 저장소를 그대로 add/push하지 않는다.

공통 부분은 studio 엔진·스키마·공통 제작 스킬·디자인 기준·테스트·샘플 brief다. Codex 진입점은 AGENTS.md와 .codex/agents, Claude는 CLAUDE.md와 .claude/agents로 구성한다. 사용자가 선택한 실행 도구가 같은 산출물 계약·상태·검수 규칙을 사용하도록 한다. 도구별 어댑터는 선택사항으로 표시하고 실제 설치/현재 호출을 점검한다. doctor의 고정 상태 문자열은 공개 전 실제 감지로 바꿔야 한다.

절대 홈 경로는 프로젝트 루트 기반 상대 경로와 환경 변수로 바꾼다. Claude 스킬 링크는 배포 폴더 안의 상대 링크 또는 복사본으로 검증한다. Codex/Claude 각각 새 폴더에서 실행, doctor·샘플 init/ingest·테스트까지 확인한다. fixture를 콘텐츠 품질 PASS로 바꾸지 않는다.

개인 runs/work/음성 후보/고객 자료/사용 기록/로그/로컬 브랜드 원본은 공개 패키지에 기본 포함하지 않는다. .env·API 키·토큰·키체인 값·웹훅·로그인 세션·계정 정보도 제외한다. 환경 설정 예시는 변수 이름과 빈 값만 제공한다. 예제는 가상의 브랜드와 데이터로 작성한다. 폰트/동봉 디자인 스킬의 라이선스와 공개 저작권 고지는 유지한다.

배포용 파일 목록과 개인정보 제외 결과를 먼저 검토 가능한 산출물로 만들고, GitHub 대상 저장소와 공개 범위가 정해진 다음 push한다. 이 문서는 Codex/Claude 선택 실행기가 이미 완성됐다는 주장이 아니다.
