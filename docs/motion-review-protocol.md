# 모션 2층 검수 절차

자동 제작·초안 저장과 최종 품질 판정을 분리한다. Producer는 기존 승인 안에서 수정·렌더·저장을 계속하며, 미관찰 항목만 사람 검수 대기로 남긴다. 두 도구 모두 [공통 기준](motion-design-standard.md)과 동일한 원장/해시 계약을 사용한다.

## 1층: 자동 대리 검수

Producer가 로컬 `python3 scripts/motion_review_evidence.py --video CURRENT.mp4 --output-dir NEW_QA_DIR --manifest motion-review-input.json`을 실행한다. 비용/외부 호출은 없으며 기존 폴더를 덮어쓰지 않는다. 현재 영상 SHA와 manifest SHA를 함께 남긴다. manifest를 준비하지 못한 경우 옵션을 생략하고 미측정 항목을 명시한다. 원장의 현재 VIDEO SHA와 증거 SHA가 같은지 독립 QA가 확인한다.

실제 구현 범위:

- ffprobe: 길이·프레임률·해상도·코덱·픽셀 포맷·색 태그·오디오 스트림.
- ffmpeg: 전체 디코드 오류 검사, 약 1초 간격(긴 파일은 최대 24칸)의 콘택트시트와 샘플 타임코드, 첫/마지막 프레임, 오디오 파형, 전체 파일 loudnorm 측정 JSON/원시 로그. 오디오 없는 파일은 `NO_AUDIO`, 무음/짧은 파일의 측정 불가 값은 `UNMEASURABLE`로 표시.
- 제공된 텍스트 안정 노출 구간: 글자 수/최소 시간/부족 시간, font_px 대비 H, 선택한 안전 직사각형 대비 bbox. 이는 **렌더러 인계값**으로서 자동 OCR/실제 가독성 증명이 아니다.
- 제공된 레이어의 시간별 실제 평가 위치: 유한차분 속도·가속도 CSV. 동일 easing 이름만으로 곡선을 발명하지 않는다. 샘플/원본이 없으면 `NOT_PROVIDED`; 선언된 값은 실제 렌더 일치 확인 전 `AUTHOR_DECLARED_UNVERIFIED`.
- 제공된 음향/시각 이벤트 타임코드: 프레임 오차와 목록. 오디오 이벤트를 자동 인식하거나 파형과 의미적 싱크가 확인됐다고 주장하지 않는다.

`evidence.json`의 `status=PROXY_EVIDENCE_ONLY`, `observed_video=false`, `observed_audio=false`를 유지한다. 이 패킷은 QA PASS 제출 파일이 아니다. 개별 결함은 원인 레이어/타임코드·새 복구 가설로 수정하고 증거를 재생성한다. 플랫폼 실기기 가림, 광과민성 전수 검출, 실제 재미·무게·소리의 마감은 이 도구가 판정하지 않는다.

## 자동 도구의 입력 패킷

시간은 현재 렌더 시작 기준 초, bbox는 현재 출력 px, 안전 영역은 [left, top, right, bottom]의 0~1 비율이다. `stable_start/end`는 실제로 모두 읽을 수 있도록 정착하고 가림이 없는 구간을 렌더러가 내보낸다. 텍스트 목록은 자막·제목·날짜·CTA·고지를 모두 포함하고 누락은 별도 기록한다. 속도 데이터는 키프레임 사이를 실제 엔진으로 평가한 샘플을 내보낸다.

```json
{
  "video_sha256": "현재 영상의 64자리 SHA256",
  "safe_rect": [0.06, 0.15, 0.80, 0.65],
  "texts": [{"id": "caption-01", "text": "내가 먼저 배우는 AI", "stable_start": 1.0, "stable_end": 3.2, "font_px": 54, "bbox": [100, 700, 800, 800], "role": "body"}],
  "layer_samples": [{"id": "title", "samples": [{"t": 0.0, "x": 100, "y": 300}, {"t": 0.1, "x": 140, "y": 300}, {"t": 0.2, "x": 160, "y": 300}]}],
  "events": [{"id": "settle", "visual_time": 0.2, "audio_time": 0.22}]
}
```

## 2층: 독립 정상 속도 시청

현재 영상/음성 해시와 검수자 ID를 기록한다. 제작자와 다른 사람이 최종 Viewer 검수에서 정상 속도 연속 시청·청취, 무음 시청을 수행하고 타임코드·레이어·문제·수정 가설을 남긴다. 루프는 최소 3회 경계를 반복 확인한다. 일부 프레임과 느린 재생은 마감 진단의 보조다.

| 상황 | 제작/검수 표현 | 다음 행동 |
|---|---|---|
| 측정 중/파일 없음/입력 STALE | `PROXY_PENDING` 또는 해당 실행 `BLOCKED` | 원인 단계만 복구; 가능한 다른 단계 계속 |
| 실제 결함 확인 | 해당 게이트 `FAIL` | 레이어 수정→재렌더→새 SHA로 검수 |
| 자동 증거 확보, 정상 속도 미관찰 | 제작 상태 `DRAFT`, 검수 진행 `AWAITING_HUMAN_REVIEW`; 해당 관찰 게이트 `BLOCKED` | 초안·증거·남은 검수 저장/전달; 반복 승인 질문 없이 대기 |
| 정상 속도 관찰 완료 | 관찰 범위에 따른 기존 `PASS/FAIL/BLOCKED` | 자동으로 다른 미검수 게이트를 PASS로 바꾸지 않음 |
| 모든 현재 게이트 PASS | 기존 release 계약으로 `FINAL` | 요청된 로컬 납품 수행; 외부 게시 권한과 구별 |

진행 표현은 새 QA enum이 아니다. CLI 게이트는 기존 PASS/FAIL/BLOCKED를 유지한다. 사용자 '전체 승인'이나 '좋다'가 직접 현재 파일을 보고 들었다는 근거가 없으면 시청 완료로 등록하지 않는다. 사람 확인을 무인 제작 매 단계의 승인으로 바꾸지 않는다. 실제 시청 가능 도구가 있다면 관찰을 보충할 수 있지만 미시청을 선언으로 메우지 않는다.

## 3단계 루브릭

해당 장르에 필요한 축만 선택하고 각 축의 관찰 근거·타임코드를 기록한다. 미관찰은 점수 대신 `NOT_OBSERVED`; 미달이 하나라도 남으면 품질 PASS 금지. '기준'은 해당 항목이 목적을 충족한다는 뜻이며 전체 출고 자동 승인이 아니다. 탁월은 개수/자가 점수로 주장하지 않는다.

| 축 | 미달 | 기준 | 탁월 |
|---|---|---|---|
| 콘셉트/정보 | 전환이 정보와 무관, 새 정보 없이 반복 | 시각적 은유와 공개 순서가 목적을 명확히 전달 | 전환·형태 변화 자체가 발견/회수를 만들고 관찰자가 메시지를 이해 |
| 타이포/구도 | 미독해·가림·한글 기준선/줄바꿈 충돌 | 현재 폰 화면에서 위계·읽기·안전영역 충족 | 글자의 조형·변형까지 의미/정서 전달에 기여하고 리프레이밍도 일관 |
| 운동/시선 | 모든 요소 동시 이동, 동일 입장 반복, 이유 없는 정지 | 주/보조 위계와 이징·정착이 시선을 안내 | 레이어 안무와 물성이 서사를 만들고 시작/끝·연결까지 세밀하게 맞음 |
| 전체 리듬 | 읽기 부족/정보 공백·긴 지루함 | 애니매틱부터 전체 강약과 정보 속도 유지 | 컷·정착·쉼이 장르 목적을 강화하고 핵심 사건을 기억하게 함 |
| 소리/무음 | 발화 가림·싱크 충돌, 소리 없으면 메시지 소실 | 실제 믹스 명료, 무음 메시지 성립 | 음악/음성/SFX가 사건의 감정을 강화하며 과잉 없이 무음판도 완결 |
| 마감/납품 | 떨림·알파/합성 오류, 누락/왜곡/잘림 | 실제 렌더·색/오디오·소스·장르별 정확성 충족 | 가장자리·깊이·경계·각 비율 마감이 일관되고 장르 핵심 성능이 특히 선명 |

비교 기준작이 있으면 동일 조건으로 이 표를 각각 채운다. 측정값은 근거로 활용하되 정상 속도 품질·시청률·모델 우월성으로 등치하지 않는다.

## 현재 엔진의 적용 범위

공통 기준은 여러 모션 장르에 적용되지만 기존 `studio` 출고 게이트/의존성은 광고형 숏폼 계약이다. `new_information_after5s`, `not_caption_only`, `voice_candidates_listened`와 VOICE/CAPTION 등 모든 단계 필수 조건이 짧은 로고·무내레이션 작품에 그대로 맞지는 않는다. 해당 없는 항목을 관찰한 것처럼 True로 채우거나 fixture/가짜 음성·자막으로 메우지 않는다. 장르별 인계에는 `genre_review`에 적용/비적용 항목·이유·관찰 범위를 명시한다. 이는 보조 검수 패킷이며 현재 CLI의 필수 게이트를 대체하지 않는다. 광고 계약이 맞지 않는 장르는 초안·편집 소스·검수 증거를 저장하고 `GENRE_RELEASE_CONTRACT_NOT_IMPLEMENTED`로 기록한다. 장르별 출고 계약이 실제 구현·검증되기 전 자동 FINAL을 약속하지 않는다.

현재 자동 도구는 증거 수집과 완성 초안의 앞부분 추출을 제공한다. 사전 애니매틱/전문 모션은 Producer가 실제 렌더 명령·소스·결과를 별도로 인계해야 한다. CLI `compose`는 정적 합성, 제공 Blender 명령은 fixture, Claude 스틸/UI 어댑터는 전문 모션 전편을 지원하지 않는다. 문서/모션 패킷이 있다는 이유로 이 경로가 연결됐다고 보고하지 않는다. 연결 확인/적합한 로컬 구현 안에서 가능한 제작을 계속한다.

`studio.adapters.technical_check(video, duration, delivery_spec)`에는 `aspect_ratio`(9:16/16:9/1:1)와 `audio_required`를 명시할 수 있다. 생략 시 기존 세로/오디오 필수 검사를 유지한다. 기술 검사 설정이 출고 게이트나 실제 시청 조건을 바꾸지는 않는다.
