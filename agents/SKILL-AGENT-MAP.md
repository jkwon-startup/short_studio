# 스킬↔에이전트 맵

기존 전역 정책/개인 스킬은 수정하지 않았다. 전역 레지스트리·맵에 프로젝트를 등록하고 pipeline-short-studio 진입 스킬을 추가했다.

- `studio-produce` → `producer` (Producer)
- `studio-research` → `research` (Research)
- `studio-rights` → `fact-rights` (Fact & Rights)
- `studio-story` → `story-script` (Story & Script)
- `studio-visual` → `director` (Director)
- `studio-visual` → `art` (Art)
- `studio-visual` → `three-d` (3D)
- `studio-visual` → `motion` (Motion)
- `studio-voice` → `voice` (Voice)
- `studio-audio` → `audio` (Audio)
- `studio-edit` → `editor-caption` (Editor & Caption)
- `studio-qa` → `technical-qa` (Technical QA)
- `studio-qa` → `viewer-qa` (Viewer QA)
- `studio-recovery` → `recovery-release` (Recovery & Release)

## 공통 광고 기준 연결

새 역할을 추가하지 않고 기존 10개 studio 스킬과 14개 역할이 docs/advertising-creative-standard.md를 읽는다. studio-visual의 Director/Art/Motion/3D 및 studio-qa의 Viewer QA는 모션그래픽을 선택한 장면에 docs/motion-design-standard.md도 적용한다. .claude/skills는 공통 .agents/skills를 참조한다.
