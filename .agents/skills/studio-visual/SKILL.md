# 실행 계약

화면 비율(brief.format: 9:16/16:9/1:1)별 구도·안전영역·자막 위치·컷 리듬은 [docs/format-guide.md](../../../docs/format-guide.md)를 따른다.

Shot의 모든 필드를 정의하고 한 순간 한 메시지를 지킨다. 의미 없는 로고/연도/진행바/장식/중복 글자/상하단 상시 정보 금지. 시선·대비·여백·전경/배경을 검수한다. 필요한 만큼 BACKGROUND/MIDGROUND/SUBJECT/OBJECT/SHADOW/LIGHT/PARTICLE/TEXT/FOREGROUND를 분리하고 움직임 공간을 확보한다. 한 장 확대 반복 금지. 구도·타이포·카메라·모션·에셋·리듬·음향·전환을 바꿔 스타일을 구분한다. Blender는 공간 의미가 있을 때 사용한다.

입력은 production ID와 현재 파일 경로/해시. 출력은 단계 컨텍스트, 산출물, 상태, 증거, 다음 단계 인계. 저장은 Producer가 `python3 -m studio ingest`로 수행한다. 실행 전에 `python3 -m studio status ID`와 `resume ID`를 확인한다. 미연결 어댑터는 BLOCKED로 남긴다. 전역 레지스트리 수정과 외부 공개는 별도 승인 대상이다.

## 몰입·리듬 계약

제작·복구·검수 시 [공통 기준](../studio-produce/references/attention-and-pacing.md)을 읽는다. 내용에 맞는 전체 상황·행동 근접·입력·결과·수정 전후의 구도 변화를 설계한다. 같은 작은 카드/휴대폰+상단 제목의 정면 구도를 관성적으로 반복하지 않는다. 반복 줌·무관한 장식 대신 새로운 사건과 주시 대상에 모션을 연결한다.

## 광고 창작·품질 계약

제작·복구·검수 전 [실사·카피·영상미 기준](../../../docs/advertising-creative-standard.md)을 읽는다. 기본 실사풍 광고에 맞게 인물·공간·행동·시선·빛·색·심도·카메라 거리와 결과/반응을 설계한다. 모션 선택 이유와 구도/컷/음향의 강약을 기록하며 브랜드를 그래픽 전편으로 확대해석하지 않는다. 연결된 고품질 이미지 도구의 실제 출력으로 실사풍 인물·공간·손·의상·소품·빛·원근·합성 공간을 확인한다. 기준 이미지와 인물 시트를 관리하고 단순 도형을 실사 미연결의 자동 대체로 쓰지 않는다. 실사에서는 행동/표정/시선과 카메라에 운동 이유를 부여한다. 모션그래픽은 docs/motion-design-standard.md를 읽고 타이포·키프레임·이징·레이어 안무·변형/매트·소리·마감을 설계한다. 반복 줌/페이드 카드로 전문 품질을 주장하지 않는다.

## 모션 단계 인계와 검수

모션이 포함된 작업은 [공통 모션 기준](../../../docs/motion-design-standard.md)을 읽고 해당 역할 범위에서 장르별 목적·사전 애니매틱·브랜드 모션 토큰을 인계한다. [정량·납품 기준](../../../docs/motion-delivery-spec.md)의 공식/권장/미확인을 구별하고 [2층 검수](../../../docs/motion-review-protocol.md)의 자동 증거와 실제 정상 속도 관찰을 분리한다. 미관찰은 해당 검수만 사람 확인 대기로 남기며 가능한 제작·수정·저장은 재승인 질문 없이 계속한다.
